# Article → EPUB v2

Версия с серверным прокси для изображений.

## Что изменилось

- статья извлекается через Jina Reader;
- изображения обнаруживаются в Markdown;
- каждое изображение скачивается через Cloudflare Worker;
- изображения физически помещаются в `EPUB/images/`;
- EPUB ссылается на локальные изображения внутри архива;
- строгий режим останавливает сборку, если хотя бы одно найденное изображение не удалось встроить;
- интерфейс показывает количество найденных и встроенных изображений и журнал загрузки.

## Почему нужен Worker

Статический сайт на GitHub Pages не может гарантированно скачивать изображения с других сайтов из-за браузерных CORS-ограничений. Worker выполняет запросы к изображениям на серверной стороне и возвращает их фронтенду.

## Самый простой деплой

1. Создай Cloudflare аккаунт.
2. Открой Workers & Pages → Create → Worker.
3. Вставь содержимое `worker.js`.
4. Deploy.
5. Открой выданный адрес вида `https://article-to-epub.<subdomain>.workers.dev/`.

После этого отдельный GitHub Pages вообще не нужен: Worker сам отдаёт интерфейс и API.

## Wrangler

Если используется CLI:

```bash
npm install -g wrangler
wrangler login
wrangler deploy
```

## Файлы

- `worker.js` — полностью автономный Worker: и интерфейс, и API.
- `index.html` — фронтенд отдельно, если захочется размещать его отдельно.
- `wrangler.toml` — конфигурация для Wrangler.
